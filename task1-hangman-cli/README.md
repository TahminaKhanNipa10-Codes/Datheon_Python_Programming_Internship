# 🎮 Hangman Word Guessing Game (Console)

**Datheon Python Programming Internship - Task 1**

An interactive, modular console game implementing string manipulation and control flow. The user attempts to guess a hidden word letter by letter within 6 attempts.

## 🎯 Project Features

* **ASCII Art Visuals:** Dynamic gallows art that updates with each incorrect guess.
* **Word Selection:** Randomly selects secret words from a dataset/list.
* **Game Logic:** Tracks previously guessed letters and prevents duplicate penalty deductions.

## 🛠️ Technology Stack

* **Language:** Python 3
* **Standard Library:** `random`

## 🚀 How to Run

1. Navigate to the project directory:

   ```bash
   cd hangman-cli
   ```

2. Run the game script:

   ```bash
   python hangman.py
   ```
