# 📈 Stock Portfolio Performance Tracker

**Datheon Python Programming Internship - Task 2**

A Python utility built to calculate real-time portfolio valuation and persist performance logs to a CSV file.

## 🎯 Project Features

* **Data Persistence:** Logs portfolio tracking data and transaction histories into a CSV format.
* **Valuation Calculation:** Automates the math behind tracking stock values and performance.

## 🛠️ Technology Stack

* **Language:** Python 3
* **Standard Library:** `csv`

## 🚀 How to Run

1. Navigate to the project directory:

   ```bash
   cd investment-tracker
   ```

2. Run the tracker script:

   ```bash
   python tracker.py
   ```

   *(Note: Replace `tracker.py` with your actual filename if different.)*
