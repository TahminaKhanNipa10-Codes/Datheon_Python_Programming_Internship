🤖 Rule-Based Customer Support Chatbot

Datheon Python Programming Internship - Task 4

A smart, terminal-based customer support chatbot built with Python. This bot uses Regular Expressions (Regex) and JSON data parsing to identify user intents, extract keywords, and provide contextual responses based on a predefined FAQ dataset.

🎯 Project Features
Intent Matching: Uses Python's re module to accurately map user input to specific FAQ categories.
Dynamic Dataset: Loads the knowledge base directly from the sample_faq.json file.
Conversational Flow: Understands standard greetings and exits gracefully on commands like bye, exit, or quit.
Graceful Fallbacks: Provides a helpful default navigation message when a user's query is unrecognized.
🛠️ Technology Stack
Language: Python 3
Libraries: re (Regex), json, sys
Interface: Command Line Interface (CLI) / Terminal
📂 Project Structure
chatbot.py - The core Python script containing the state management and regex logic.
sample_faq.json - The structured dataset containing greetings and FAQs (hours of operation, project submission, certificate issuance).
🚀 How to Run the Project
Open your terminal or command prompt.
Navigate to the project directory (if not already there):
cd task4-rule-based-chatbot
Run the Python script:
python chatbot.py
Start chatting! Try asking:
"What are your hours?"
"How do I submit my internship project?"
"When will I receive my certificate?"
